# 🏦 SwiftATM - Logic-Based Web Simulation

A sleek, functional ATM web application built to master **JavaScript Phase 2** concepts. This project focuses on handling user state, mathematical logic, and dynamic DOM updates.

## 🌟 Features
- **Authentication:** Simulated PIN entry system to unlock account features.
- **Transaction Logic:** Real-time updates for withdrawals and deposits.
- **Validation:** Prevents overdrafts and handles invalid inputs (non-numbers).
- **Persistent UI:** Interactive dashboard that responds to user actions without page reloads.

## 🛠️ Technical Breakdown
- **DOM Manipulation:** Selecting and updating elements based on user interaction.
- **State Management:** Tracking the "Balance" variable throughout the session.
- **Event Listeners:** Handling button clicks and form submissions efficiently.
- **Conditionals:** Complex `if/else` logic to manage banking rules.
